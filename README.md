# Nook-Interiors

A static landing page for Nook Interiors, a luxury interior design business based in Alamo, CA.

## Tech stack

This is a single static HTML file (index.html) with all CSS embedded inline. There is no JavaScript framework, build step, or backend, just plain HTML and CSS, plus a Google Fonts CDN link for typography.

## Running locally

No installation or dependencies are required.

## Option 1, open directly

Clone or download this repository, then open index.html in your browser (double-click it, or use File > Open).

## Option 2, serve with a local static server (recommended)

This ensures relative paths behave the same as they would on a real deployment. From the project folder run:

npx serve .

Then open the URL it prints (usually http://localhost:3000). Alternatively, use an editor extension such as VS Code's Live Server.
